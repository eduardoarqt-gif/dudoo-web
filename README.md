# Dudoo Web

App (PWA) do Dudoo para iPhone: Hoje, Projetos, Portal do cliente e Financeiro.
Instalação: abra o link de conexão enviado pelo Dudoo no Safari → Compartilhar → Adicionar à Tela de Início.

Sem chaves neste repositório: a conexão (endereço e chave) vem no link de conexão e fica só no aparelho.
